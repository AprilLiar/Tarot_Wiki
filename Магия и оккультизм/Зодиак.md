# Зодиак

Кратко: двенадцать знаков зодиака, основа магии и [[Стойки|Стоек]].

## Описание
Знак существа определяется по дате рождения. Календарь и вся эзотерика взяты из нашего мира один к одному.

Каждый знак связан с одним из двенадцати [[Иархи|Иархов]].

Собственный знак мага наносится на [[Камни заклинаний|камень]] вдвое быстрее и без проверки.
