# Правила ведения вики Тарошной

Это хранилище Obsidian (vault) с вики мира Тарошной. Claude ведёт его по разговорам с автором (Bogdan).

- Язык вики: только русский.
- Коммитить и пушить напрямую в `main`, без веток и PR. Автор ничего не подтверждает и не пулит вручную.
- Каждая статья — отдельный `.md` файл в папке своего раздела. Имя файла = название статьи (например `Регионы/Пепельная Долина.md`).
- Ссылки между статьями — вики-ссылки Obsidian: `[[Название статьи]]`. Ссылаться можно и на ещё не созданные статьи.
- У каждого раздела есть оглавление `Раздел/Раздел.md`; новую статью добавлять в оглавление своего раздела.
- Новые статьи начинать с шаблона из `Шаблоны/`. Frontmatter: `тип`, `теги`, `статус` (черновик / канон).
- Новый раздел можно создать, если ни один существующий не подходит; тогда добавить его в `Главная.md`.
- Не выдумывать канон сверх сказанного автором. Свои предложения помечать блоком `> [!idea] Предложение Claude`.
- Противоречия с уже записанным не исправлять молча, а спрашивать автора.
