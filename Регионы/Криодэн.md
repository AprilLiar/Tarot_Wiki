# Криодэн

Кратко: человеческий город, самый технологически развитый регион [[Люди|людей]].

## Описание
В Криодэне научились использовать ледяные эффекты [[Камни заклинаний|магических камней]], чтобы создавать невероятно прочные сплавы, а также магниты и подобное для производства энергии.
